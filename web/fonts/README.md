# Fonts of the web client

These are subsets (Latin letters and the punctuation the client uses) in WOFF2 format, made with fontTools from
the official releases. Their licences reserve the original names for unmodified fonts, so the subsets carry names
of their own.

| File | Made from | Licence |
| --- | --- | --- |
| `nv-serif-*`, `nv-display-*` | Source Serif 4 (Adobe) | `LICENSE-SourceSerif.md` |
| `nv-sans-*` | IBM Plex Sans (IBM) | `LICENSE-IBMPlex.txt` |
| `nv-condensed-*` | Barlow Condensed (The Barlow Project Authors) | `LICENSE-BarlowCondensed.txt` |
| `nv-text-*` | Source Sans 3 (Adobe) | `LICENSE-SourceSans.md` |

All four are under the SIL Open Font License 1.1.
